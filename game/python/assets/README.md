# Assets Directory

This directory contains all game assets for the Python version of the car racing game.

## Required Assets:
- `car.png` - Player car sprite
- `obstacle.png` - Obstacle car sprite  
- `road.png` - Road background texture
- `crash.wav` - Collision sound effect
- `engine.wav` - Engine sound effect
- `score.wav` - Scoring sound effect
- `powerup.wav` - Power-up collection sound

## Asset Specifications:
- Images should be PNG format with transparent backgrounds
- Sounds should be WAV format for PyGame compatibility
- Recommended car size: 50x100 pixels
- Recommended obstacle size: 50x100 pixels
- Road texture should be tileable
